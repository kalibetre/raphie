A scheduled job sends a saved prompt to its bot once or at a fixed interval. Each job is a [work item](/guides/conversations/#work-items) of the bot's, and every run's result posts in the bot's [chat](/guides/conversations/), wherever the job was created. Jobs run only while Raphie is running; overdue work runs once when it comes back.

For a one-time nudge about something in your backlog, set a [work item reminder](/guides/conversations/#reminders-for-work-items).

Results always appear in the chat. You can also send them to one home channel per bot, such as a Telegram chat.

## Create a job

<Tabs>
<TabItem label="In Settings">

<Steps>

1. Open **Settings**, choose the bot, then **Scheduled jobs**, and choose **Create job**.
2. Enter a **Job name** and the **Prompt** the bot should act on.
3. Under **Schedule**, choose **Once** or **Recurring**. For Recurring, set **Repeat every (minutes)**.
4. Pick the **First run date** and **Time (local)**, in your browser's time zone.
5. Choose **Schedule job**.

</Steps>

</TabItem>
<TabItem label="In the chat">

Ask the bot, for example "In two minutes, tell me the time and a funny saying" or "Every 24 hours, summarise my open tasks". The bot saves the job with its scheduling tools, without asking for approval, and posts in the chat when the job runs.

You can also ask the bot to list, change, pause or delete its jobs. A bot can only see and change its own jobs, and only in its chat with you, in a reply that stays private: a group or a task from another bot can't see or schedule them.

</TabItem>
</Tabs>

Make sure the bot has a working model connection before a job is due; otherwise the run fails.

## How schedules work

There is no cron syntax. A job has a first run time and, optionally, a repeat interval:

| Field        | Meaning                                                                                |
| ------------ | -------------------------------------------------------------------------------------- |
| First run    | A date and time (Settings), or a delay in seconds from now (when the bot schedules it) |
| Repeat every | Whole minutes, from 1 to 525,600 (one year). Empty means the job runs once.            |

The interval is elapsed time, not a calendar rule: "every 1,440 minutes" drifts by an hour across a daylight saving change, and the next run is counted from when the previous one was sent, not from the original time.

When a job is due, its prompt runs as a **scheduled** turn in the job's own session, apart from your chat, the way [background work](/guides/conversations/#background-work) does. The session is kept while the job exists, so each run can build on the job's earlier runs; it doesn't read your chat. If the bot is replying in the chat, or the job's previous run is still going, the run waits until it is free; background work on other items doesn't hold it back.

When the run ends, its reply is posted in the chat as the bot's message, exactly as the run wrote it, with a tab under the bot's name: the job's name, **scheduled**, and a stamp with how the run ended. Any [cards](/guides/conversations/#cards) the run showed appear under the post, and the bot reads their rows with it. Pressing the tab opens the job's item under **Settings → Work**, and **Reply** under the message quotes it. The bot reads it with your next message, so you can reply to it like any other. If the bot is in the middle of a reply when the post arrives, you see the post at once, and the bot reads it with your next message, so it never changes a reply halfway. If the run fails or is cancelled, the post says so in the bot's words, such as `I couldn't finish "Morning brief": the calendar was down`, with the reason when there is one.

## Manage jobs

Each job card in **Scheduled jobs** shows its state and last run.

| Action      | Effect                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Run now** | Queues one extra run without moving the schedule. Works on paused jobs; refused if the bot is busy or the job is still running. |
| **Pause**   | Stops future runs. A run already submitted continues.                                                                           |
| **Resume**  | Restarts the job; an overdue job runs straight away.                                                                            |
| **Remove**  | Stops future runs. Its earlier runs stay in the chat.                                                                           |
| **Confirm** | Shown only on a job saved before Raphie recorded who makes a job. Its runs then follow the chat's permission mode.              |

Pausing or removing a job does not cancel a run already in progress or undo actions it took. A run doesn't use the chat, so **Stop** in the chat leaves it running; **Cancel run** on the job's item under **Settings → Work** stops it.

Under **Settings → Work**, a job's item shows its next run and is active while the job runs on schedule, waiting while it is paused, and done once it is removed or a one-time job has run. Change the job itself under **Scheduled jobs**.

**Run history** lists each run as queued, running, completed, failed or interrupted, each opening the chat at that run's post once it is made. Finished runs also appear on the Notifications page until you open or dismiss them.

## Send results to a home channel

Each bot has one home channel. Every scheduled run, wherever its job was created, also sends its reply there. The default is **Web only**.

<Tabs>
<TabItem label="From the chat">

Send `/home` in a verified private Telegram chat or an authorised Discord or Slack conversation. In a Telegram group, send `/home@YourBotName`. The command works without a model call and confirms the change.

</TabItem>
<TabItem label="From Settings">

Open **Settings**, choose the bot, then **Channels**. Under **Home channel**, choose **Set as home** on a known conversation, or **Use web only**. A conversation appears here once it has messaged the bot or sent `/home`.

</TabItem>
</Tabs>

- Replies at home are labelled "Scheduled: job name" and use the channel's normal [delivery](/guides/telegram/#delivery-limits-and-recovery), including chunking and retries.
- The destination is fixed when each run starts. Changing home affects later runs only.
- If home is disconnected, disabled or its account was revoked, runs stay web-only. Raphie does not fall back to another channel or resend missed notifications later.
- Replying in a private home chat writes in the bot's [chat](/guides/conversations/); replying in a home group continues that group's session.
- Approvals for a scheduled run are decided in the web workspace. Home receives only an "Approval needed" notice. With the chat on **Full access**, a run asks for none.

:::caution
Everyone in a group chosen as home can read every scheduled reply. Pick a group only for jobs whose output you would share there.
:::

## Missed runs and restarts

Timing is durable: jobs survive restarts without your doing anything.

| Situation                               | What happens                                                                                                                                                |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Raphie was down when a job was due      | The job runs once when Raphie starts. Missed intervals are not replayed.                                                                                    |
| A run starts over 60 seconds late       | It is marked **Late** in run history and Notifications.                                                                                                     |
| The bot is busy or waiting for approval | The run waits, shown as **Waiting for bot**. It never expires and never skips an approval.                                                                  |
| Submitting the turn fails               | Raphie tries four times in all, waiting 1, 2 and 4 seconds between attempts. Then the run is recorded as failed and a recurring job schedules its next run. |
| Raphie stops during a run               | The run's turn is recovered on the next start like any other turn. A run whose turn is stopped or aborted is recorded as interrupted.                       |

A scheduled prompt's tool calls follow the chat's permission mode: on **Ask** they need approval like any other; on **Full access** they run without asking. Only the bot's chat can create, change or delete a job, and only in a reply that stays private, so a group or a task from another bot can never schedule work that runs unasked.

Jobs saved before Raphie recorded who makes a job may have come from a group or another bot. Their runs ask before each action, whatever the chat's mode, until you press **Confirm** on the job's card. Rewriting its prompt from the chat confirms it too; a new time, a pause or **Resume** does not, since none of them shows you what it will run.

## Limits

| Limit                        | Value                                                              |
| ---------------------------- | ------------------------------------------------------------------ |
| Jobs per bot                 | 100                                                                |
| Job name                     | 80 characters                                                      |
| Prompt                       | 4,000 characters                                                   |
| Repeat interval              | 1 to 525,600 minutes                                               |
| Home channels per bot        | One; no per-job destinations                                       |
| Run history kept             | Active and unread runs, plus the newest 500 dismissed runs per bot |
| Push notifications to phones | None; results appear in the clients and at home                    |
