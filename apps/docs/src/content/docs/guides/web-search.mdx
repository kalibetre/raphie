Every bot can search the web with its `web_search` tool. The search runs through the bot's own model connection, so there is no other account or key to set up. It works with OpenRouter connections and ChatGPT subscription sign-ins; other connections cannot search yet.

A bot decides when to search: for current events, facts it is unsure of, and anything its memory and workspace do not hold. It gets back an answer with numbered sources, which it cites when it replies.

## How a search works

The tool sends one request on the conversation's model, with the provider's search turned on:

| Connection           | How it searches                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| OpenRouter           | OpenRouter's web plugin. OpenAI, Anthropic, Google and some other models search with their own provider; other models through Exa. Up to five results. |
| ChatGPT subscription | OpenAI's Responses API with its `web_search` tool, on your subscription's sign-in.                                                                     |

The bot can also name pages to read along with the query.

The answer is returned to the bot as web content, not instructions. Text in a web page cannot tell the bot what to do.

## Approval, data and cost

| Question                  | Answer                                                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Does a search ask first?  | No. Searching only reads, like the memory tools, and runs in every session, including handed-off tasks.     |
| What leaves your machine? | The query and any pages the bot names, sent to the model provider, which already receives the conversation. |
| What does it cost?        | One extra model request per search, plus any search charge, billed to the bot's connection or subscription. |
| Which model searches?     | The conversation's model.                                                                                   |

## Limits

| Limit                       | Value                                       |
| --------------------------- | ------------------------------------------- |
| Connections that can search | OpenRouter, ChatGPT subscription            |
| Results read per search     | 5 on OpenRouter; chosen by OpenAI otherwise |
| Extra pages per search      | 10                                          |
| Answer length               | About 600 words                             |
| Time before a search fails  | 90 seconds                                  |

When the bot's connection cannot search, the tool says so and the bot tells you; it does not make results up.
