A new Raphie has no account and no model. You create the single administrator from a terminal on the machine running Raphie, sign in from a browser, connect a provider to the default bot, and start talking. After that you can use the browser, the [desktop app](/start/installation/#desktop-app) or both. It takes about five minutes.

## Set up Raphie

<Steps>

1. **Check Raphie is running.**

   ```sh
   raphie health && echo ok
   ```

   If it fails, see [check it worked](/start/installation/#check-it-worked).

2. **Create the administrator.** The web workspace stays locked until you do; its sign-in page tells you so. In a terminal on the same machine:

   ```sh
   raphie auth setup              # user install
   sudo raphie auth setup         # Linux system service
   bun run raphie auth setup      # source checkout
   ```

   Enter an email, then a password of at least 12 characters, twice. The password is never echoed or accepted as an argument. There is only ever one administrator.

3. **Sign in.** Open the web workspace and sign in with that email and password.

   | Install        | Default address                                                             |
   | -------------- | --------------------------------------------------------------------------- |
   | User install   | `http://127.0.0.1:24320` (`4320` for installs made before ports were saved) |
   | System service | `http://127.0.0.1:41837`                                                    |
   | Source         | `http://127.0.0.1:4320`                                                     |

   If you chose another port, `raphie port` prints the address. On a remote server, open an SSH tunnel to its web port first, for example `ssh -L 24320:127.0.0.1:24320 you@server`. See [remote access](/operate/remote-access/).

4. **Meet your first teammate.** A fresh Raphie welcomes you, then asks you to name the default bot (Raphie, unless you change it) and pick its colour. Both can change later in **Settings → Profile**.

5. **Connect a model provider.** The bot then asks for a way to think: **First, I need a way to think.** Choose a model service there. The web workspace opens the connection form in place; the desktop app opens the bot's **Providers** page with that form open. You can also skip onboarding and use **Settings → Providers → Add connection** at any time. Pick one:

   - **OpenRouter:** paste an API key from your [OpenRouter keys page](https://openrouter.ai/settings/keys).
   - **ChatGPT subscription:** choose the sign-in button and finish signing in on the page it opens. If your browser is on a different machine from Raphie, the final redirect to `127.0.0.1` fails; copy that address from the browser bar and paste it back into Raphie.

   Connections belong to the bot you are configuring, and keys are encrypted on this machine. Details are in [credentials](/operate/credentials/).

6. **Pick a default model.** Open **Models**, find a model from your new connection and choose **Set as default**. New conversations start with it; existing ones keep their model.

7. **Start a conversation.** Once the bot can reply, it opens on its empty desk: choose one of the things to ask, or type in the composer, and send. You can switch models per conversation from the composer.

</Steps>

## Use the desktop app

On a Mac, the desktop app is an alternative to the browser for everyday use. Setup stays the same: you still create the administrator with `raphie auth setup`, and you approve each new device from a browser that is signed in.

<Steps>

1. [Install the app](/start/installation/#desktop-app) and open it.

2. Enter the same address you signed in to above, or Raphie's `https://` tailnet address if it runs on another machine.

3. Choose **Open approval page** in the app, check in your signed-in browser that the code matches, and choose **Approve device**.

</Steps>

Conversations, approvals and settings are the same in both; a reply read in one counts as read in the other.

:::tip[Forgot the password?]
Run `raphie auth recover` on the server (`sudo raphie auth recover` on the system service). It sets a new password, signs out every browser and device, and removes all passkeys. See [authentication](/operate/authentication/).
:::
